# Graph Coloring

## Generating Test Cases
* To generate random test cases, just run the following command:
> python generate_test_cases.py
* then insert the number of nodes and the number of edges you want to generate.
* it will generate for you both the graph in form of adjacency list and adjacency matrix
* generate as much test cases as you need, then you can just run the sequential on all of them using the "automateTests.py" script
* to run it, just run the following command:
> python automateTests.py
